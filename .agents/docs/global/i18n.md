# Hướng Dẫn Vận Hành & Sử Dụng Đa Ngôn Ngữ (i18n)

Tài liệu này hướng dẫn quản lý, bổ sung và kiểm soát đa ngôn ngữ trong hệ thống zalobot, ánh xạ trực tiếp với tri thức canonical [`i18n.md`](../../knowledge/global/i18n.md).

## 1. Nguyên Tắc Hoạt Động & Ngôn Ngữ Hỗ Trợ

- **Ngôn ngữ hỗ trợ**: `vi` (Tiếng Việt - mặc định) và `en` (English).
- **Cơ chế fallback**: Khi locale bị thiếu, không hợp lệ hoặc chuỗi chưa dịch, hệ thống tự động fallback về `vi`.
- **Lưu trữ trạng thái người dùng**:
  - **zalo Bot**: Lưu trong trường `users.preferredLocale` trong cơ sở dữ liệu. Menu lệnh, tin nhắn trả lời và cron nhắc việc tự động đọc giá trị này tại thời điểm gửi.
  - **Web Dashboard**: Lưu trong cookie `zalobot-locale`. `LocaleProvider` đọc cookie để hydrate giao diện và đồng bộ thuộc tính `lang` trên thẻ `<html>`.

## 2. Quy Chuẩn Thêm & Quản Lý Translation Keys

Toàn bộ translation keys được quản lý tập trung tại `packages/contracts/src/index.ts` (thuộc `@zalobot/contracts`):

1. **Khai báo song ngữ bắt buộc**: Khi thêm một key mới, bắt buộc phải định nghĩa nội dung cho cả `vi` và `en` trong đối tượng `messages`.
2. **Cú pháp nội suy động (Interpolation)**: Sử dụng cú pháp `{variableName}` và truyền qua tham số `values` của hàm `translate(locale, key, values)` hoặc `t(key, values)`.
3. **Định dạng số và ngày tháng**: Dùng helper `localeTag(locale)` (`'vi-VN'` cho `vi`, `'en-US'` cho `en`) khi gọi `Intl.NumberFormat` hoặc `Intl.DateTimeFormat`. Múi giờ nghiệp vụ luôn giữ cố định là `Asia/Ho_Chi_Minh`. Khi Gemini tạo JSON, mọi luồng đều nhận mốc thời gian hiện tại từ `DEFAULT_TIMEZONE`: tool-call qua system prompt, còn OCR trực tiếp qua prompt chuyên biệt.

## 3. Bề Mặt Áp Dụng & Hướng Dẫn Trong Giao Diện Web

### Bề Mặt Bắt Buộc Sử Dụng i18n

- **Giao diện người dùng Web Dashboard**:
  - JSX text children, button labels, input placeholders.
  - Tiêu đề cột của bảng dữ liệu (`DataTableColumn.header`), tiêu đề và mô tả panel (`DataPanel.title`, `DataPanel.description`).
  - Trạng thái rỗng (`emptyMessage`), thông báo lỗi (`inline-alert`, `alert`), và nhãn trợ năng (`aria-label`).
  - Chuỗi fallback (ví dụ: `t('common.notSet')` thay vì `'Chưa đặt'`).
- **Tin nhắn và phản hồi zalo Bot**: `ctx.reply`, `sendMessage`, text của các nút `Markup.button`.
- **Mẫu email, template HTML thông báo**, nội dung nhắc việc qua cuộc gọi tự động (CallMe).
- **Thông điệp phản hồi / lỗi từ API** hiển thị trực tiếp cho người dùng cuối.

### Ví Dụ Chuẩn Trong React / Next.js Component:

```tsx
import { useLocale } from '@/shared/providers/locale-provider';
import { localeTag } from '@zalobot/contracts';

export function MyScreen() {
  const { t, locale } = useLocale();

  const formattedDate = (value?: string) =>
    value ? new Intl.DateTimeFormat(localeTag(locale)).format(new Date(value)) : t('common.notSet');

  return (
    <DataPanel title={t('debts.panel.title')} description={t('debts.panel.description')}>
      <DataTable
        ariaLabel={t('debts.table.ariaLabel')}
        emptyMessage={t('debts.table.empty')}
        columns={[
          {
            id: 'counterparty',
            header: t('debts.columns.counterparty'),
            cell: (row) => row.counterparty,
          },
        ]}
        rows={[]}
      />
    </DataPanel>
  );
}
```

### Ngoại Lệ Kỹ Thuật Được Phép (Không Dịch)

- Log hệ thống (`logger.log`, `console.error`, v.v.).
- Dữ liệu callback của zalo button (`ACTION_CONFIRM`, `ACTION_CANCEL`, v.v.).
- Đường dẫn API và navigation routes (`API_ROUTES.*`, `APP_ROUTES.*`).
- Tên bảng/cột cơ sở dữ liệu, enum kỹ thuật, mã lỗi nội bộ backend.
- Dữ liệu người dùng tự nhập hoặc dữ liệu từ bên thứ ba (Google Workspace, zalo profile data).

## 4. Kiểm Thử & Kiểm Soát Tự Động (Pre-commit)

- Hệ thống pre-commit và validator (`scripts/agent-system/validators/i18n-strings.ts`) tự động quét mã nguồn staged để phát hiện chuỗi ký tự hardcode hiển thị người dùng.
- Lệnh kiểm tra hệ thống: `npm run agent-system:validate`.
