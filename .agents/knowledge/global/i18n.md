# Internationalization & Multi-Language Architecture

## Purpose

System-wide i18n invariants for user-facing text on the web dashboard, Zalo bot replies, reminder notifications, public pages, and client-visible API messages. Translation keys are strictly typed.

## Catalog & Helpers (`packages/contracts/src/index.ts`)

- `SUPPORTED_LOCALES = ['vi', 'en']`, `DEFAULT_LOCALE = 'vi'`, `normalizeLocale(value)` (invalid → `vi`), `localeTag(locale)` (`vi-VN` / `en-US`).
- `messages.vi` / `messages.en` hold every key; `TranslationKey` is derived from the catalog.
- `translate(locale, key, values)` falls back to the `vi` text, then to the key itself, and replaces `{name}` placeholders.

## Locale Resolution

- **Web**: `LocaleProvider` reads cookie `zalobot-locale` on mount (default `vi`); `setLocale` writes the cookie (1 year, `SameSite=Lax`) and sets `<html lang>` to `localeTag(locale)`. The root layout renders `<html lang="vi-VN">`. The locale selector lives in the sidebar navigation (`app-navigation.tsx`). Components use `t(key, values)` from `useLocale()`.
- **Bot**: `users.preferredLocale` (default `vi`). `ReminderSchedulerService` reads it at dispatch to pick `reminder.header.text` and format time with `localeTag(locale)` in `Asia/Ho_Chi_Minh`. `UsersService.setPreferredLocale` exists but nothing calls it; there is no bot command to change locale.
- **LLM prompts**: `LlmService` calls receive a current date-time anchor from `getVietnamDateTimeContext` (text input uses config `timezone` = `DEFAULT_TIMEZONE`; the receipt OCR flow uses the default zone).

## Invariants

1. **Zero hardcoded user-facing literals** in web code: JSX text, buttons, placeholders, table headers, panel titles/descriptions, empty/error states, aria labels, metadata, toasts.
2. **Both locales**: every key exists in `vi` and `en`.
3. **Interpolation**: dynamic values go through named placeholders (`{userName}`, `{amount}`).
4. **Locale-aware formatting**: `Intl.NumberFormat(localeTag(locale))` / `Intl.DateTimeFormat(localeTag(locale))`; business time stays `Asia/Ho_Chi_Minh`. Use fallback keys (e.g. `common.notSet`) instead of literals.
5. **Not translated**: API routes (`API_ROUTES`, `APP_ROUTES`), tool names (`TextToolType`), confirmation verbs/codes (`yes <code>`), DB table/column names, log strings, third-party error codes, user-entered data.

## Current Gap

Most API bot replies (strategies under `apps/api/src/zalo/text/strategies/`, confirmation cards) are inline Vietnamese strings; `translate` is used in the API only for the reminder header. New bot text should use catalog keys.
